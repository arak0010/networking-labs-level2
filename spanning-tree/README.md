# Spanning Tree Protocol Configuration

## Objective
Prevent switching loops and maintain network redundancy by using
Spanning Tree Protocol (STP).

## Description
This lab demonstrates how Spanning Tree Protocol prevents Layer 2 loops
in networks with redundant links by placing certain switch ports into a
blocking state while keeping backup paths available.

## Environment
- Multiple interconnected switches
- Redundant links
- Packet Tracer lab environment

## Tasks Performed
- Built a redundant switched network
- Observed root bridge election
- Identified port roles and states
- Verified loop prevention behavior

## Notes
Topology visualization is based on a standard redundant switched network.
STP operation was verified through port state observation rather than
visual topology changes.
