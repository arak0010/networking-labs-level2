# EtherChannel Configuration

## Objective
Increase bandwidth and provide link redundancy by bundling multiple
physical switch links into a single logical EtherChannel connection.

screenshots/topology.png

This Packet Tracer topology demonstrates EtherChannel configuration
between switches, allowing multiple links to operate as one logical
interface for improved performance and reliability.

## Environment
- Two or more switches
- Multiple physical links between switches
- Packet Tracer lab environment

## Tasks Performed
- Configured multiple switch interfaces for EtherChannel
- Created a channel group
- Verified EtherChannel operation
- Tested link redundancy and load balancing
