# Routing and DHCP Configuration

## Objective
Configure routing along with DHCP services to automatically assign IP
addresses to network devices and enable communication between multiple
networks.

![Routing and DHCP Topology]
(screenshots/topology.png)

This Packet Tracer topology demonstrates router-based DHCP configuration
combined with routing to allow automatic IP address assignment and
inter-network connectivity.

## Environment
- Router-based DHCP
- Multiple LAN segments
- Packet Tracer lab environment

## Tasks Performed
- Configured DHCP address pools
- Assigned default gateway and DNS settings
- Enabled routing between networks
- Verified dynamic IP assignment
- Tested end-to-end connectivity
