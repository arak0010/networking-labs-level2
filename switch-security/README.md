# Switch Security Configuration

## Objective
Improve network security by restricting unauthorized access to switch ports
using basic switch security features.

screenshots/topology.png

## Description
This lab demonstrates how switch security features prevent unauthorized
devices from accessing the network by limiting MAC address learning on
access ports.

## Environment
- Managed switches
- End devices
- Packet Tracer lab environment

## Tasks Performed
- Configured switch access ports
- Enabled port security
- Defined allowed MAC addresses
- Tested violation modes
- Verified security behavior

## Notes
This lab focuses on configuration validation and behavior testing rather
than topology visualization. Security effectiveness was verified through
port access behavior.
